# Manuel utilisateur d’Écokin

## 1. Introduction
Écokin est une plateforme web permettant de signaler des problèmes environnementaux, de suivre leurs traitements et de partager des ressources utiles entre les acteurs concernés.

## 2. Accéder à la plateforme
1. Ouvrez votre navigateur.
2. Accédez à l’URL de votre application Django.
3. Vous arrivez sur la page d’accueil d’Écokin.

## 3. Créer un compte
1. Cliquez sur le bouton “Inscription”.
2. Remplissez les informations demandées.
3. Validez votre inscription.

## 4. Se connecter
1. Cliquez sur “Connexion”.
2. Saisissez votre nom d’utilisateur et votre mot de passe.
3. Validez pour accéder à votre espace.

## 5. Signaler un problème
1. Depuis le menu, cliquez sur “Signaler”.
2. Remplissez le formulaire avec le titre, la description, la photo et la localisation.
3. Soumettez le signalement.
4. Une analyse IA peut apparaître automatiquement pour proposer une catégorie et une priorité.

## 6. Consulter les signalements
- Vous pouvez consulter vos signalements depuis “Mes signalements”.
- Les autorités peuvent voir l’ensemble des signalements depuis leur espace.
- La carte permet de visualiser les signalements géographiquement.

## 7. Utiliser la section Ressources
1. Ouvrez “Ressources”.
2. Consultez les guides, livres, publications et autres documents.
3. Vous pouvez publier une nouvelle ressource depuis “Publier une ressource”.
4. Les commentaires peuvent être ajoutés sur chaque ressource pour faciliter la collaboration.

## 8. Collaborer avec les partenaires
- Les autorités, ONG, écoles et entreprises peuvent partager des ressources.
- Les commentaires permettent d’échanger des idées et des suggestions.

## 9. Conseil de sécurité
- Protégez votre mot de passe.
- Ne partagez pas d’informations sensibles dans les commentaires.
- Vérifiez toujours la validité des documents partagés.
